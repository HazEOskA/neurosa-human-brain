# NEUROSA-HB

> Give your agents a brain, not just a context window.

NEUROSA Human Brain Runtime is an independent, local-first, programmable cognitive layer for agentic systems. It provides persistent, plastic, and auditable cognition without binding callers to one agent framework, model provider, cloud, or graph database.

## Recovery build

This repository is a functional reconstruction after an earlier unpushed scratch workspace was deleted. It does not claim exact source or Git-object recovery.
